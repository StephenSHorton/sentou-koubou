# Starter projects

Pre-built anim-editor projects (bones + fullbody ref + starter keys).

## Load in the editor

1. Open http://127.0.0.1:8777/ (server must root at `char-anim-pipeline/`)
2. Click **Load Brennen starter** or **Load Whitney starter**
3. Or **Import project** → pick a JSON here

## Files

| File | Contents |
|------|----------|
| `brennen-starter-project.json` | Combat fullbody, 21-bone rig, idle/attack/hit/dead keys |
| `whitney-starter-project.json` | Same for Whitney + hat bone |

## After load

1. **Rig** — nudge bones if the silhouette is off
2. **Animate → Idle → Play**
3. **Animate → Attack → Play**
4. Export full project when you like the timing
